# 4-E-1B｜分類順序與特殊分類 Icon

本更新包已累積包含 4-E-1 與 4-E-1A 的修正。

## 首頁與探索全台展覽共同順序

桌面版固定排列為：

- 演唱會｜快閃店｜動漫｜美術｜設計
- 攝影｜市集｜音樂｜自然
- 歷史｜表演｜舞蹈｜電影
- 親子｜競賽｜科技｜其他

兩個頁面都直接使用同一個 `CATEGORY_ORDER`，
不會各自維護不同順序。

即使某分類目前為 0 筆，也會保留在分類選單中，
方便未來新增競賽、快閃店或其他活動。

## 特殊 Icon

- 演唱會：獨立麥克風線框 Icon
- 快閃店：獨立快閃店面＋閃光線框 Icon

快閃店 Icon 不與市集、商店或其他分類共用。

## 舊資料相容

以下舊分類會自動轉換：

- 快閃 → 快閃店
- 快閃活動 → 快閃店
- 期間限定 → 快閃店
- 歷史文化 → 歷史
- 自然科學 → 自然

## 設計保護

- 不包含 `index.html`
- 不改 Hero、Logo、卡片與詳細頁版型
- 只更新分類順序、分類 Icon、分類資料與桌面排列
