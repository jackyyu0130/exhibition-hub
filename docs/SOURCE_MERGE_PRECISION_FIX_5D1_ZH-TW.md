# 5-D.1｜表演活動去重精準度修正

## Artifact 105 發現的問題

5-D 技術執行成功，但以下四筆華山活動被判定為新活動，
實際上已存在於既有資料：

- 星空下的魔笛
- 再見，馬麻！
- 把書吃掉｜西遊太空篇
- 擁抱海洋永續親子音樂會

來源標題會加入劇團名稱與活動系列前綴，
既有售票資料則使用作品名稱，因此完整字串相似度不足。

## 修正

1. 比對 `《作品名稱》`、`「作品名稱」`、`『作品名稱』`
   的核心標題。
2. 核心作品名稱相同、日期相容且場館一致時可自動合併。
3. 不同作品即使同場館、日期重疊，也不會自動合併。
4. 單一表演的華山列表區間若明顯大於既有精確演出日期，
   合併時保留既有較精確日期。
5. 表演系列總頁仍可使用官方完整活動期間。

## 發布狀態

本修正不修改正式活動檔，不修改前台，也不修改 Workflow。
上傳後重新執行既有 source merge Trigger 即可。
