# 4-E-1A｜分類名稱精簡與演唱會獨立分類

本包已包含上一版 4-E-1 的圖片、官方連結與分類 Icon 修正，
不需要再另外上傳舊版 4-E-1。

## 分類順序

- 快閃｜美術｜攝影｜設計
- 動漫｜歷史｜自然｜親子
- 音樂｜演唱會｜表演｜舞蹈｜電影
- 市集｜競賽｜科技｜其他

## 名稱調整

- `歷史文化` → `歷史`
- `自然科學` → `自然`

舊網址或舊資料仍使用 `歷史文化`、`自然科學` 時，
前台會自動轉成新名稱，不會造成舊連結失效。

## 演唱會獨立分類

原本 `contentType: concert` 會歸入「音樂」，
本版改為獨立的「演唱會」分類，並新增麥克風線框 Icon。

- `concert` → `演唱會`
- `music_festival` 仍歸入 `音樂`
- 演唱會活動不會再重複計入「音樂」
- 目前候選資料中有 35 筆 `concert` 類型活動

## 設計保護

- 不包含 `index.html`
- 不改 Hero、Logo、卡片結構或 RWD
- 首頁與探索頁共用同一套分類名稱、順序與 Icon
