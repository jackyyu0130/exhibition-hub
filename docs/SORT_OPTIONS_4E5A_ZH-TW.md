# 4-E-5A｜探索頁排序選單調整

排序選單改為：

1. 推薦排序
2. 熱門排序
3. 名稱排序
4. 時間排序

## 排序規則

### 推薦排序

依網站既有推薦分數排序，綜合活動熱度、圖片完整度、
是否正在舉辦、是否即將結束與資料完整度。

### 熱門排序

優先依 `hitRate` 由高到低排列；
熱度相同時，再用推薦分數決定順序。

### 名稱排序

依繁體中文活動名稱排列。

### 時間排序

依展期距離今天由近到遠：

- 正在舉辦的活動優先
- 即將舉辦的活動依開始日期由近到遠
- 已結束活動依結束日期距離今天由近到遠
- 缺少日期的活動排在最後

舉辦狀態仍由左側「全部展覽／目前舉辦／即將舉辦／
即將結束／免費展覽」按鈕控制，不再混入排序選單。
