# 6-C2｜北部場館矩陣與前台展演場地選擇器

## 範圍

北部涵蓋臺北市、新北市、基隆市、桃園市、新竹市、新竹縣與宜蘭縣。

## 場館資料

`data/northern_venue_matrix.json` 記錄場館正式名稱、別名、行政區、場館類型、
父園區、內部空間、官方頁面及來源策略。

世貿一館、台北國際會議中心、南港展覽館一館及二館使用不同 venueId；
即使未來共用同一檔期來源，仍依實際地址與展區分流。

## 前台

探索展覽頁左側保留「展演場地」入口與已選場館摘要。
完整選擇器採右側大型抽屜；手機版改為全螢幕 Bottom Sheet。

功能：

- 場館關鍵字與別名搜尋
- 縣市、行政區分組
- 場地類型快速切換
- 多選場館
- URL `venue=` 以逗號保存多個場館
- 左側與結果上方顯示已選條件
- 延續奶茶、木質、日式溫暖留白風格

## 發布安全

本階段新增場館矩陣與前台選擇器，不直接啟用全部 planned Collector。
正式資料來源仍依 Dry Run、去重與品質 Gate 分批啟用。
