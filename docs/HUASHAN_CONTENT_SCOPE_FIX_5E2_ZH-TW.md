## 人工內容檢查發現

雖然結構閘門通過，部分欄位仍混入華山頁面的
「相關活動」卡片與共用頁尾資料：

- 多場活動重複出現其他活動的主視覺
- 個別票價同時混入下一場活動的票價
- 共用連結 `tea.huashan1914.org/beingproject`
  與 `reurl.cc/33kmg9` 被當成活動外部連結
- 徵件獎勵禮券被誤判成付費入場
- 徵件、課程類內容未進入排除審核

## 修正

1. 遇到「相關活動／更多活動／推薦活動／如何來華山」
   後停止收集圖片與外部網址。
2. 圖片最多保留 3 張，排除 Emoji 圖片。
3. 票價優先讀取第一個票價區塊，不再掃描整頁所有金額。
4. 長篇售票介紹只保留票種與金額片段。
5. 禮券、獎金、贈品等非入場費不判定為付費。
6. 徵件、招募、工作坊、講座、課程等標記為
   `exclude_review`。
7. 移除華山共用專案與短網址。
