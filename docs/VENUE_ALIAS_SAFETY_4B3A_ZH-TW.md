# 4-B-3A｜場館別名安全修正

Registry Dry Run 59 已成功支援多場館活動，但發現
`臺中國家歌劇院` 的過短別名 `歌劇院` 會誤把
`衛武營國家藝術文化中心歌劇院` 配對成臺中國家歌劇院。

本批次：

- 移除泛稱 `歌劇院`
- 保留 `臺中國家歌劇院`、`台中國家歌劇院`、`台中歌劇院`
- 新增明確廳別別名：
  - 臺中國家歌劇院大劇院
  - 臺中國家歌劇院中劇院
  - 臺中國家歌劇院小劇場
- 新增防止誤判的自動測試
- 不修改 `data/exhibitions.json`
- 不影響已解析活動總數

修正後：

- 已解析活動仍為 1,093
- 配對率仍為 46.43%
- 多場館活動由 94 筆調整為 88 筆
- 6 筆原本被錯加臺中國家歌劇院的活動恢復為單一場館
