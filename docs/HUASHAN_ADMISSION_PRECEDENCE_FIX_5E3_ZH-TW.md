# 5-E.3｜華山票價狀態優先順序修正

## Artifact 117 結果

5-E.2 已修正：

- 28／28 詳情頁成功
- 相關活動圖片不再混入
- 共用網址歸零
- 徵件獎勵不再當成票價
- 徵件與課程類進入 `exclude_review`

但人工檢查發現：

- `2026華山親子表藝節`
- `priceText` 明確包含 8800 元與 9800 元
- `admission` 卻被判定為 `free`

## 原因

詳情頁其他文字出現「免費參加」，舊邏輯先掃描整頁免費字樣，
再判斷已整理出的正式票價，因此免費訊號錯誤覆蓋明確票價。

## 修正順序

1. 已整理出的明確金額、全票、優待票、愛心票、早鳥價、原價
   → `paid`
2. 已整理出的免費入場文字
   → `free`
3. 全頁明確售票制文字
   → `paid`
4. 全頁明確免費入場文字
   → `free`
5. 其餘
   → `unknown`

- 不修改 Workflow
