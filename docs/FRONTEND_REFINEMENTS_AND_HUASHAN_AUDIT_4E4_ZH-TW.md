# 4-E-4｜日曆與分類版面修正

## 日曆

- 選取日期改為暖色淺底、深色文字
- 不再使用黑底白字
- 選取其他日期後，今日日期改為淡色提示
- 再次點擊已選日期可取消日期篩選

## 首頁分類

- 電腦版固定每排 6 個
- 分類卡縮短並保持原有風格
- 17 個分類排列為 6／6／5

## 探索全台展覽分類

- 每排 6 個圓形 Icon
- 只有圓形 Icon 可點擊與懸浮
- 分類文字獨立顯示在圓圈下方
- 右側分類區改為 3 排，降低整體高度
- 左側介紹區不再被右側高度拉長

## 華山資料缺口

目前 `huashan-1914` 在來源登錄表中為：

- `status: planned`
- `enabled: false`

現有更新器主要抓取文化部 API，尚未建立華山官方網站 Collector。
因此未出現在文化部 API 的華山活動不會自動匯入。

`CHIIKAWA DAYS 台北特展` 應由後續的華山官方 Collector 處理，
不建議只手動加入單筆資料，否則每日更新後可能再次消失。
