二、GitHub Desktop
1. Current Repository：exhibition-hub
2. Current Branch：develop
3. 點 Fetch origin；若變 Pull origin，再點 Pull origin
4. Repository → Show in Finder
5. 解壓安全更新包，打開：
   exhibition-hub-v6.5.0-r1-huashan-ci-hotfix-safe-update
6. 將資料夾「裡面的內容」複製到 exhibition-hub 根目錄
7. macOS 詢問時點 Replace／取代
8. 確認 Changes 不包含：
   data/exhibitions.json
   data/exhibitions.enriched.json
   data/geocode-cache.json
9. Summary 輸入：
   Fix Exhibition Hub V6.5.0-R1 Huashan CI and detail recovery
10. 點 Commit to develop
11. 點 Push origin

三、Pull Request
1. 點 Preview Pull Request
2. base：main
3. compare：develop
4. PR 標題：
   Fix Exhibition Hub V6.5.0-R1 Huashan CI and detail recovery
5. 點 Create pull request
6. 等 All checks have passed
7. 點 Merge pull request
8. 點 Confirm merge

四、正式部署
1. GitHub 儲存庫上方點 Actions
2. 左側點 Update data and deploy site
3. 確認最新一筆 main 工作自動開始
4. 若沒有，點 Run workflow
5. Branch 選 main
6. 再點 Run workflow
7. 等 Success
8. 開啟 https://twexhibition.com/
9. 按 Command + Shift + R

六、復原
- 尚未 Commit：Branch → Discard All Changes
- 已 Commit 未 Push：History → 右鍵 R1 提交 → Undo Commit
- 已 Push 未合併：Pull Request → Close pull request
- 已合併：該 Pull Request → Revert → 建立並合併復原 PR
