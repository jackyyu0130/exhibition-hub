Exhibition Hub V6.5.0-R2 最短更新流程

請使用：
Exhibition-Hub-V6.5.0-R2-cumulative-repair-safe-update.zip

1. GitHub Desktop 切換到 exhibition-hub／develop。
2. Fetch origin；若顯示 Pull origin，再點一次。
3. 確認 No local changes。
4. 解壓 R2 安全更新包。
5. 將解壓資料夾「裡面的內容」複製到 exhibition-hub 根目錄並取代同名檔案。
6. Changes 不應包含 data/exhibitions.json、data/exhibitions.enriched.json、data/geocode-cache.json。
7. Summary 輸入：Apply Exhibition Hub V6.5.0-R2 cumulative repair
8. Commit to develop → Push origin。
9. 建立 develop → main Pull Request，標題同上。
10. 等 Validate development changes 與 Run project tests 全綠後再合併。
11. Actions → Update data and deploy site → 確認 main 工作 Success。
12. 開啟 https://twexhibition.com/，Mac Chrome 按 Command + Shift + R。

完整檢查與復原方式請看：REPLACEMENT_GUIDE_V6.5.0-R2_ZH-TW.md
