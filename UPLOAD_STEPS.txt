Exhibition Hub V6.5.0｜最短安全更新流程

建議下載：
Exhibition-Hub-V6.5.0-hero-postcard-carousel-safe-update.zip

一、GitHub Desktop
1. Current Repository：exhibition-hub
2. Current Branch：develop
3. 點 Fetch origin；若變 Pull origin，再點 Pull origin
4. Repository → Show in Finder
5. 解壓安全更新包，打開：
   exhibition-hub-v6.5.0-hero-postcard-carousel-safe-update
6. 將資料夾「裡面的內容」複製到 exhibition-hub 根目錄
7. macOS 詢問時點 Replace／取代
8. 確認 Changes 沒有 data/exhibitions.json、data/exhibitions.enriched.json
9. Summary 輸入：
   Apply Exhibition Hub V6.5.0 hero postcard carousel
10. 點 Commit to develop
11. 點 Push origin

二、Pull Request
1. 點 Preview Pull Request
2. base：main
3. compare：develop
4. PR 標題：
   Apply Exhibition Hub V6.5.0 hero postcard carousel
5. 點 Create pull request
6. 等 All checks have passed
7. 點 Merge pull request
8. 點 Confirm merge

三、正式部署
1. GitHub 儲存庫上方點 Actions
2. 左側點 Update data and deploy site
3. 若沒有自動執行，點 Run workflow
4. Branch 選 main
5. 再點 Run workflow
6. 等 Success
7. 開啟 https://twexhibition.com/
8. 按 Command + Shift + R

四、前台確認
- 桌機 Hero 同時兩組票券＋明信片
- 左箭頭下一組，右箭頭上一組
- 手機左滑下一組，右滑上一組
- 手機首頁有日曆、分類、展區、免費
- 手機探索卡片徽章文字置中

五、復原
- 尚未 Commit：Branch → Discard All Changes
- 已 Commit 未 Push：History → 右鍵該提交 → Undo Commit
- 已 Push 未合併：Pull Request → Close pull request
- 已合併：該 Pull Request → Revert → 合併復原 PR
