Exhibition Hub V6.4.2｜最短安全更新流程

建議檔案：
Exhibition-Hub-V6.4.2-visual-regression-hotfix.zip

1. GitHub Desktop 左上 Current Repository 選 exhibition-hub。
2. 上方 Current Branch 切到 develop。
3. 點 Fetch origin；若變成 Pull origin，再點 Pull origin。
4. 確認左側顯示 0 changed files。
5. macOS 最上方點 Branch → Update from main；若可按，點 Update develop。
6. 解壓縮 Exhibition-Hub-V6.4.2-visual-regression-hotfix.zip。
7. 開啟 ZIP 內 exhibition-hub-v6.4.2-visual-regression-hotfix。
8. GitHub Desktop 點 Repository → Show in Finder。
9. 把更新包「裡面的所有內容」貼到：
   /Users/jacky_yu/Documents/GitHub/exhibition-hub
10. Finder 詢問同名檔案時，勾全部套用，再點取代。
11. 回 GitHub Desktop，確認仍為 develop。
12. 確認左側不包含：
    data/exhibitions.json
    data/exhibitions.enriched.json
13. Summary 輸入：
    Apply Exhibition Hub V6.4.2 visual regression fixes
14. Description 留白。
15. 點 Commit to develop。
16. 點 Push origin。
17. GitHub 網頁 → exhibition-hub → Pull requests。
18. 有開啟中的 develop → main PR 就點進去；沒有才點 New pull request。
19. 設定 base: main、compare: develop。
20. PR 標題輸入：
    Apply Exhibition Hub V6.4.2 visual regression fixes
21. 點 Create pull request。
22. 等所有檢查綠色，再點 Merge pull request → Confirm merge。
23. GitHub → Actions → Update data and deploy site。
24. 確認最新 main 工作為綠色 Success。
25. 等待 2～10 分鐘，開啟 https://twexhibition.com/。
26. macOS Chrome 按 Command + Shift + R；手機建議用無痕分頁檢查。
