Exhibition Hub V6.4.1｜最短安全更新流程

建議更新方式：先 develop、測試成功後再合併 main。

1. GitHub Desktop 左上 Current Repository 選 exhibition-hub。
2. 上方 Current Branch 切換 develop。
3. 點 Fetch origin；若變成 Pull origin，再點 Pull origin。
4. 確認 0 changed files 後，macOS 上方點 Branch → Update from main，讓 develop 先包含正式站最新資料；若選項不可按，表示已同步。
5. 若出現未提交變更：
   - 只看到 .DS_Store：取消勾選或在 Finder 刪除後再繼續。
   - 有自己正在修改的檔案：先 Commit 到目前分支，不要直接覆蓋。
6. 建議解壓縮 Exhibition-Hub-V6.4.1-mobile-drawer-hotfix.zip。
7. 開啟 ZIP 內 exhibition-hub-v6.4.1-mobile-drawer-hotfix 資料夾，選取「裡面的所有內容」，貼到：
   /Users/jacky_yu/Documents/GitHub/exhibition-hub
8. Finder 詢問同名檔案時，選「全部取代」；不要把外層資料夾再套進 repository。
9. 回 GitHub Desktop，確認 Current Branch 仍是 develop。
10. 左下 Summary 輸入：
   Apply Exhibition Hub V6.4.1 mobile drawer stability fixes
11. 點 Commit to develop。
12. 點 Push origin。
13. GitHub 網頁 → exhibition-hub → Pull requests。
14. 若已有 develop → main PR 就開啟它；若沒有，點 New pull request，base 選 main、compare 選 develop。
15. PR 標題輸入：
    Apply Exhibition Hub V6.4.1 mobile drawer stability fixes
16. 等所有檢查綠色，再點 Merge pull request → Confirm merge。
17. GitHub → Actions → Update data and deploy site，確認 main 的最新執行為綠色 Success。
18. 點執行結果中的 https://twexhibition.com/，或等待 2～10 分鐘後重新載入。
19. 瀏覽器使用無痕視窗，或強制重新整理：
    macOS：Command + Shift + R
    Windows：Ctrl + F5
